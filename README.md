# Best Reminder

Best Reminder is a small native Android app that reminds you every day: "I am the best."

## Features

- Simple affirmation screen
- Daily notification at the time you choose
- Notification permission handling for Android 13+
- Reminder rescheduling after device reboot

## Build

Open this folder in Android Studio, or build from the command line once the Android SDK is installed:

```bash
./gradlew assembleDebug
```

The app uses only platform Android APIs and Java; no runtime dependencies are required.
