# Best Reminder Android App

Simple Android app that reminds you every day: **"You are the best."**

## Features

- One-tap setup for a daily reminder notification
- Android 13+ notification permission handling
- Automatically re-schedules reminder after device reboot

## How it works

- Tap **Enable daily reminder** in the app.
- The app schedules a daily notification at **9:00 AM local time**.
- Notification message: **You are the best.**

## Open and run

1. Open this folder in Android Studio.
2. Let Android Studio sync Gradle.
3. Run the app on an emulator or Android device.
4. Tap **Enable daily reminder** and allow notifications if prompted.
